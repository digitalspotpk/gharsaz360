GharSaz 360 — Complete Setup & User Guide

Termux se GitHub Pages tak, aur GitHub Pages se Google Play Store tak — har qadam yahan maujood hai. Yeh guide developers aur end-users dono ke liye hai.

1. Termux (Android Terminal) Environment Setup

Agar aap Android phone par hi terminal se kaam karna chahte hain, Termux install karein (F-Droid se recommended, Play Store version purana ho sakta hai).

1
Packages update karein: 
pkg update && pkg upgrade -y
2
Zaroori tools install karein: 
pkg install git nodejs-lts python gh -y
3
Storage permission dein (files transfer karne ke liye): 
termux-setup-storage
4
Versions verify karein: 
git --version
node --version
python --version
gh --version

2. Project Folder Banayen & Local Test

1
Project folder banayen aur files copy karein: 
mkdir -p ~/gharsaz360 && cd ~/gharsaz360
# index.html, app.js, manifest.json, sw.js, privacy-policy.html,
# guide.html aur sab icon PNGs isi folder mein copy karein
2
Local server chalayen: 
python -m http.server 8080
3
Browser mein kholein (Chrome recommended for PWA testing): 
http://localhost:8080

App load hote hi 3-second splash screen dikhega, phir Dashboard khulega. Chrome DevTools → Application tab mein jakar "Service Workers" aur "Manifest" check kar sakte hain.

3. GitHub Pages Deployment (GitHub CLI)

1
GitHub CLI se login karein: 
gh auth login
2
Naya repository banayen aur push karein: 
cd ~/gharsaz360
git init
git add .
git commit -m "Initial commit: GharSaz 360"
gh repo create gharsaz360 --public --source=. --remote=origin --push
3
GitHub Pages enable karein (branch publishing): 
gh api -X PUT repos/:owner/gharsaz360/pages \
  -f "source[branch]=main" -f "source[path]=/"

Ya GitHub website par: Repo → Settings → Pages → Branch: main → / (root) → Save.

4
Kuch minutes baad app live ho jayegi is URL par: 
https://<your-username>.github.io/gharsaz360/

4. Play Store Packaging (PWA → APK/AAB)

Option A — PWABuilder.com (Easiest, no-code)

1
Browser mein https://www.pwabuilder.com kholein.
2
Apna GitHub Pages URL paste karein aur "Start" dabayen — PWABuilder aapke manifest.json aur service worker ko scan karega.
3
"Android" package option select karein, phir "Generate Package" dabayen — ye ek .aab file deta hai jo Play Store upload ke liye ready hoti hai.
4
Signing key: PWABuilder khud generate kar sakta hai, ya aap apni key use kar sakte hain (recommended agar future updates bhi upload karni hain — key safe rakhein).

Option B — Bubblewrap CLI (More control)

1
Bubblewrap install karein: 
npm install -g @bubblewrap/cli
2
TWA project initialize karein: 
bubblewrap init --manifest https://<your-username>.github.io/gharsaz360/manifest.json
3
Prompts follow karein (package name jaise com.gharsaz360.app, app name, signing key details).
4
Build karein: 
bubblewrap build

Output: app-release-signed.aab — ye directly Play Console par upload hoti hai.

5. Module-by-Module Operational Guide

💰 Budgets & Income

Bottom nav → More → Budgets & Income. "+" se naya budget banayen (name, estimated amount, period). Income Sources section mein Salary/Business/Rental income add karein. Progress bar green (<70%), yellow (70–90%), red (>90%) estimated spend dikhata hai.

🧾 Expense Tracker

Bottom nav → Expenses. Main category (Grocery, Health, Daily Living, Leisure) select karte hi sub-categories auto-load hoti hain. Har expense ko kisi budget se link kiya ja sakta hai. Chips se category-wise filter karein.

🔑 House Rent

Property add karein → Tenant add karein (property se link) → Rent Payment record karein. Sub-meter calculator mein previous/current reading aur unit rate dalte hi charge auto-calculate hota hai. "Receipt" button se professional receipt generate ho kar WhatsApp ya download ke zariye share hoti hai.

👥 Udhar Khata

Naya contact add karein, phir unpar tap karke "Given" ya "Taken" transactions record karein. Balance khud-ba-khud calculate hota hai. "Remind" button WhatsApp par pre-filled reminder message khol deta hai.

🔨 Construction

Project banayen → Material expenses add karein (project se linked) → Labour register mein worker add karke daily "Present / Half-Day / Absent" mark karein. Net payout khud calculate hota hai (wage × attendance − advance).

📦 Assets & Warranty

Appliance add karein warranty expiry date ke sath. Badge automatically "Expired / X days left / X months left" dikhata hai.

🔧 Maintenance Scheduler

Task select karein (AC Servicing, Tank Cleaning, etc), last serviced aur next due date dalein. Dashboard par 14 din pehle reminder dikhega.

🚗 Vehicle Log

Vehicle add karein, phir har fuel-up par liters, rate aur odometer reading darj karein. App khud pichli entry se distance nikal kar km/liter mileage calculate karta hai.

🌙 Zakat & Charity

"Zakat Calculator" kholen — cash, gold/silver grams aur unki price, business assets aur liabilities dalein. App silver-nisab (612.36g) ke against compare karke 2.5% zakat calculate karta hai. Charity Ledger mein Sadqah/Fitrana records rakhein.

☀️ Solar & Utility

Har mahine generated/exported units aur peak/off-peak consumption dalein — estimated bill aur savings dashboard par dikhte hain.

🧺 Pantry Planner

Item ki current quantity aur minimum threshold set karein. Threshold se neeche aane par item "Shopping Checklist" mein aa jata hai — download button se text list mil jati hai.

🔒 Document Vault

Pehli dafa ek PIN set karein — is PIN se AES-256 encryption key banti hai. Ye PIN kahin save nahi hota, is liye yaad rakhein. Emergency Contacts (Doctor, Hospital, Electrician) bina PIN ke hi quick-access mein rehte hain.

🎉 Event Budgeter

Event banayen (jaise "Eid-ul-Adha Qurbani") total budget ke sath, phir line items (vendor, cost, advance) add karte jayen — progress bar overspend dikhata hai.

🎯 Savings Goals

Target amount aur date set karein. "+ Add Savings" se progress ring update hoti hai jab bhi paisay bachayen.

6. Google Play Console Upload Checklist

  • ☑ App icon: 512×512 PNG (32-bit, transparency allowed) — provided as icon-512.png.
  • ☑ Feature graphic: 1024×500 PNG/JPG — provided as feature-graphic.png.
  • ☑ At least 2 phone screenshots (16:9 or 9:16) — take these from your live GitHub Pages app.
  • ☑ Short description (max 80 chars) and full description (max 4000 chars).
  • ☑ Privacy Policy URL — point to your deployed privacy-policy.html, e.g. https://<username>.github.io/gharsaz360/privacy-policy.html.
  • ☑ Data Safety declaration: select "No data collected" since GharSaz 360 stores everything locally and has no backend server.
  • ☑ Content rating questionnaire — complete honestly (finance/utility, no objectionable content).
  • ☑ Target audience & age group — select appropriately (this app is a general finance/utility tool).
  • ☑ Upload the signed .aab from Step 4 to a new release under Production (or Internal Testing first).

7. Local Backup, CSV Export & Google Drive Sync

JSON / CSV Export & Import

Settings screen mein "Export JSON Backup" pura app data ek file mein save karta hai — isay periodically apne Drive/email par bhej dein. "Export CSV" spreadsheet-friendly summary deta hai. "Import JSON Backup" se purani backup file wapas load ki ja sakti hai (ye current data ko overwrite karti hai, is liye pehle export kar lein).

Google Drive Integration (Optional, Developer Setup)

1
Google Cloud Console mein naya project banayen aur "Google Drive API" enable karein.
2
OAuth Consent Screen configure karein aur ek "OAuth Client ID" (type: Web application) banayen, jisme aapki GitHub Pages URL "Authorized JavaScript origins" mein add ho.
3
App ke Settings module mein apna Client ID configure karein taake export ki gayi JSON file seedha aapke Google Drive "App Data" folder mein upload ho sake — is process mein koi developer server involve nahi hota.
